# Пересылка Telegram → MAX (официальный API MAX)

Проект пересылает **текстовые сообщения** из указанного Telegram-канала в указанный чат/канал MAX. Для отправки в MAX используется официальный HTTP API `platform-api2.max.ru`, а не пользовательская WebSocket-сессия из старого проекта.

## Переменные окружения Bothost

Задайте в настройках проекта:

- `TG_BOT_TOKEN` — токен Telegram-бота от @BotFather.
- `TG_SOURCE_CHAT_ID` — числовой ID Telegram-канала/группы (канал обычно имеет формат `-100...`).
- `MAX_TOKEN` — токен официального MAX-бота из кабинета разработчика.
- `MAX_CHAT_ID` — числовой ID чата/канала MAX.

## Запуск

Команда запуска: `python main.py`

Зависимости: `pip install -r requirements.txt`.

## Важно перед тестом

1. MAX-бот должен быть добавлен в целевой чат/канал. Для публикации в канале назначьте его администратором с необходимыми правами.
2. Telegram-бот должен быть добавлен в исходный канал (обычно администратором), чтобы Telegram Bot API передавал ему `channel_post`.
3. Не запускайте несколько копий программы с одним Telegram-токеном одновременно: `getUpdates` не работает одновременно с настроенным webhook и может конфликтовать с другим polling-процессом.
4. При первом запуске накопленные Telegram updates пропускаются, чтобы не переслать старую очередь.
5. На данный момент пересылаются только текст и подпись как текст. Фотографии, видео и документы не передаются как файлы. Форматирование Telegram не сохраняется.
6. Если API MAX возвращает ошибку, проверьте код и текст ответа в логах. HTTP 401 означает проблему с токеном; 403/400 часто указывают на доступ, ID чата или права бота.
