# Пересылка Telegram → MAX (текстовые сообщения)

Проект основан на исходном `maxtg-master`, но направление пересылки изменено: источник — Telegram, получатель — MAX.

## Важно перед запуском

- Поддерживается пересылка текста и подписи к фото/видео как текста. Сами фотографии, видео и документы пока не загружаются в MAX.
- Для чтения публикаций Telegram-канала добавьте своего Telegram-бота в канал администратором. Для группы проверьте разрешения бота и Privacy Mode.
- Нужны ID исходного чата Telegram и ID целевого чата MAX.
- Клиент MAX в исходном проекте использует WebSocket-протокол, не подтверждённый как официальный публичный API. Автор использует его на свой риск; возможны поломки или ограничения аккаунта.
- Не публикуйте `.env` и не передавайте никому токены.

## Настройка

1. Установите Python 3.10–3.12 (на хостинге — среду Python).
2. Скопируйте `.env.example` в `.env`.
3. Заполните `TG_BOT_TOKEN`, `TG_SOURCE_CHAT_ID`, `MAX_TOKEN`, `MAX_CHAT_ID`.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите: `python main.py`.
6. Опубликуйте тестовый текст в исходном Telegram-чате и проверьте, появился ли он в целевом чате MAX.

При первом запуске старые обновления Telegram пропускаются — пересылаются только новые сообщения.

## Переменные

- `TG_BOT_TOKEN` — токен от @BotFather.
- `TG_SOURCE_CHAT_ID` — ID Telegram-канала или группы-источника. Для канала обычно начинается с `-100`.
- `MAX_TOKEN` — токен сессии MAX, полученный способом, описанным в исходном проекте.
- `MAX_CHAT_ID` — числовой ID чата MAX-получателя.

## Развёртывание на хостинге

На VPS с Linux: загрузите архив и распакуйте его; создайте `.env`; установите Python и зависимости; запустите `python main.py`. Для постоянной работы предпочтительнее systemd или Docker, а не закрытая SSH-сессия.

На панели вроде Bothost: создайте Python-проект/приложение, загрузите файлы проекта, задайте переменные окружения (или создайте `.env`, если панель это разрешает), установите зависимости из `requirements.txt`, укажите команду запуска `python main.py` и включите автоперезапуск. Названия пунктов панели могут отличаться. Если хостинг поддерживает только Telegram Bot API/webhook и не позволяет постоянное WebSocket-соединение, этот проект там не заработает.
